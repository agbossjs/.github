# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| `0.1.0-rc` (pre-release) | Yes |
| `< 0.1.0` | No |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Report vulnerabilities privately across any `agbossjs` repository via [GitHub Security Advisories](https://github.com/agbossjs/agboss/security/advisories/new) or by emailing [security@agboss.dev](mailto:security@agboss.dev). Include reproduction steps, affected repository/package, and potential impact. We will acknowledge receipt within 48 hours.
